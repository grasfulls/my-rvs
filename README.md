# My Return Visits (my-rvs)

A lightweight, mobile-friendly Progressive Web App (PWA) designed to track, log, and map recurring locations and contacts for return visits.

## Features

- **Location Tracking:** Store geographic coordinates and map pins for recurring properties, clients, or service stops.
- **Contact Management:** Keep track of essential contact information tied directly to your return locations.
- **PWA Ready:** Installable on mobile devices with offline support via service workers.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Architecture:** Progressive Web App (Manifest & Service Worker)
